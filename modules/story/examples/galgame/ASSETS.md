# Local demonstration assets

The Mahiro character and pastel background were supplied by the project owner
for this local demo. Mahiro is from *Onimai*. These are reference/fan-demo assets,
not original Cherry Framework artwork or a grant of redistribution rights.

The transparent normal portrait was extracted from the supplied casual-clothes
reference. The happy expression was generated from the same reference, preserving
the pose and costume. Both were approved in the UI preview before integration.
The background is the supplied official-character-page pattern, converted to WebP.

Replace these three files and `mahiro.tres` when distributing an original game.
The presenter is asset-independent; this directory provides example resources.
