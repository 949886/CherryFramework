# Story 模块完善进度

按顺序实施并分别提交；测试使用 Godot 4.7.2 .NET 版的独立项目。

1. 解析器：严格结构校验、明确剧情 ID / 本地化文件映射、可读取的源文件诊断。
2. 存档：深快照、版本/结构/类型校验、事务恢复、有界迁移、原子文件替换。
3. 播放状态：画面与行内进度恢复、统一暂停/继续/自动播放/快进时间控制。
4. 扩展接口：独立表现层契约、可配置节点引用、行内命令注册与自定义处理器。
5. 编译缓存：内容与编译器版本失效，复用编译产物，每次创建独立运行时。
6. 编辑器与导出：一键库检查、位置诊断、素材/跳转/SID 校验、自动导出依赖。

完成证据与接口说明随每个 milestone 更新在此文件及对应测试中。
